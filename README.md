# Rematch Cage（重战牢笼）

支持配置「唤醒物品 -> 生物群组」一对多映射表：当表内配置的 Boss 或生物死亡时，会在原地自动生成一座内部悬浮展示该生物微缩模型的特殊刷怪笼（重战牢笼）；手持对应的唤醒物品右键即可直接再次召唤挑战。

## 多版本分支与工作树目录

- `1201forge`：`1201-forge-Rematch Cage`（Minecraft 1.20.1 Forge）
- `1211neoforge`：`1211-neoforge-Rematch Cage`（Minecraft 1.21.1 NeoForge）
- `2612neoforge`：`2612-neoforge-Rematch Cage`（Minecraft 26.1.2 NeoForge）
